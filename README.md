# SP广告周报服务

每周三 06:00（北京时间）由 n8n 触发：读飞书多维表格「领星SP广告数据」→ 生成带公式的 Excel 周报 → 上传飞书云文档（每周一个新文件）→ 写「周报归档」表 → 群机器人发卡片。

## 接口
- `GET /health` 健康检查 + 上次运行结果
- `POST /weekly` 生成周报（后台运行，立即返回）。参数（query 或 JSON）：
  - `dryRun=1` 只生成、不写飞书/不发群（结果在容器 /tmp/reports）
  - `noSend=1` 写优化记录但不上传/不发群
  - `today=YYYY-MM-DD` 指定"今天"（回溯生成某周）
  - `wait=1` 同步等待结果返回（约 1–2 分钟）
  - 请求头 `X-Api-Key`（或 `?key=`）= 环境变量 API_KEY

## 环境变量
| 变量 | 说明 |
|---|---|
| FS_APP_ID / FS_APP_SECRET | 飞书自建应用（需 bitable、drive:drive 权限） |
| FS_WEBHOOK | 群自定义机器人 webhook |
| FS_FOLDER | 云文档文件夹 token（SP广告周报） |
| API_KEY | 调用口令，n8n 请求时带上 |
| DEFAULT_TARGET_ACOS | 默认目标 ACOS，默认 0.30 |

## 周期规则
成熟期 = 截至"今天−8天"所在周之前的最后一个完整周（周日）往前 5 个完整周；新鲜周 = 紧接的一周。周三跑：成熟期到上上周日，新鲜周 = 上周。

## 优化记录
`suggest.py` 按规则生成建议，按 记录键 去重写入飞书「优化记录」：已存在的只刷新「最近数据」，不改状态。状态/执行日期/备注在飞书表里维护。
